### AI & Data Analytics Intern
**Edunet Foundation | AICTE & Shell India**  
*October 2025 – November 2025*

Completed an internship focused on Artificial Intelligence, Machine Learning, and Data Analytics, developing an image-based waste classification application using Deep Learning.

**Project: Automated Waste Classification using CNN**

Developed an end-to-end waste classification system using a Convolutional Neural Network (CNN) to identify and categorize waste materials from images.

**Key Contributions**
- Designed and trained a CNN model using TensorFlow and Keras.
- Implemented image classification across six categories: Cardboard, Glass, Metal, Paper, Plastic, and Trash.
- Applied data augmentation, batch normalization, and dropout to improve model generalization.
- Used Early Stopping and Model Checkpointing during training.
- Developed a Flask-based web application for image uploads and waste classification.
- Evaluated model performance using an unseen test dataset.

**Technologies:** Python · TensorFlow · Keras · CNN · Flask · HTML · CSS · Pillow

**Model Performance:** 58.20% test accuracy.

**Project Repository:** [Garbage Classification](https://github.com/maniraj48/Garbage-Classification)
